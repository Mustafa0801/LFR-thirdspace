
# Line following robot project for HackClub thirdspace, uses 2 motors and an array of 5 sensors, powered by 2 Li-ion batteries and uses PID algorithm

PLEASE NOTE: THE PLAYABLES FOR WEEK 1 AND 2 WERE BUGGED SO I HAVE FIXED THEM NOW, THE LINKS IN THE SUBMISSION DONT WORK SO PLEASE FIND THE DEMOS FOR WEEK 1 AND 2 IN THE PLAYABLES FOLDER

## WEEK 1
It is very important to note that this week we did not really have any of the hardware components for the robot ready e.g motors, sensors, e.t.c.
The only thing we had was the Arduino UNO; it wasn't possible to properly test any of the code so some things in the code have kinda been eyeballed.
Because of that, most of the code at the moment is not finalised and rather the code is more like a first draft.  
For the cad designs, there were a lot of linux glitches, along with save files being corrupted which meant things had to be redone.
The basic things are done but the design will be finalized before 3D printing

## WEEK 2
Had a lot of technical difficulties this week as well in obtaining the parts, and even after we got the parts, some were faulty. 
Also were unable to get chassis printed so only made a very rough version of the robot.  
Due to lack of time we weren't able to test it enough so it has many issues, only motors were tested which aren't working as intended.
However it is probably issue with the hardware rather than the code.

## WEEK 3
Hoped to finish the project this week but once again faced some technical difficulties, did everything that we needed to do however some components seem to be faulty due to which the robot is unable to move. Unfortunately we will have to continue it to the next week. it's very disappointing but it feels there is nothing we can do to make it work.

## WEEK 4
We finally completed the project this week, once again faced issues getting materials like the soldering iron and the batteries which caused things to be done at the last minute. I did think it would be difficult to get 10 hrs this week but we ended up facing so many issues that it wasn't too much of a problem.  
 \
Aaand thats the end of this project, very happy with how smooth the line follower was and how the whole project turned out despite all the techincal difficulties and hurdles!!
